# 迭代路线图

课程评分中过程性迭代占 30%，因此计划按“可演示的小步”推进，每次 PR 都有明确的
新增能力、实验或修复。

## v0.1 初步原型（当前）

- [x] 32 条中文抽象目标 + 16 条良性 prompt
- [x] 13 种静态攻击
- [x] 遗传算法进化攻击（6 段基因组、防御感知适应度）
- [x] 5 种防御配置（输入过滤 / 系统提示 / spotlight / 输出过滤）
- [x] 规则评判 + LLM judge + 集成评判
- [x] ASR / Wilson CI / 防御下降 / FPR
- [x] CLI + Gradio Demo + 自动报告
- [x] pytest 测试
- [x] 离线 Mock pilot

## v0.2 真实模型 pilot

- [ ] 接入 Qwen-2.5 / DeepSeek，跑 8 goals × 5 attacks × 4 defenses
- [ ] 规则评判器人工校准（40 条）
- [ ] 报告真实 ASR、防御下降、FPR
- [ ] 记录 API 成本与延迟

## v0.3 防御增强

- [ ] 语义过滤器：embedding 相似度 / 小型分类器
- [ ] 输出改写：把“部分配合”改写为安全回答
- [ ] 自适应防御：按类别选择不同阈值
- [ ] 消融实验：每个阶段的边际收益

## v0.4 攻击增强

- [ ] LLM 驱动的框架改写（只改写包装，不改写目标）
- [ ] 多轮攻击（追问、角色维持）
- [ ] 跨模型迁移：在 A 上进化，在 B 上测试
- [ ] 成本感知搜索：在 API 预算内最大化 ASR

## v0.5 评测与展示

- [ ] 人工标注集与 judge 校准报告
- [ ] Bootstrap 置信区间与显著性检验
- [ ] 公开排行榜页面（静态 HTML）
- [ ] Demo 增加“防御对比”和“案例回放”
- [ ] 最终报告与演示视频
