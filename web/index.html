评测流水线

5 个阶段
  1. 01
    攻击生成

    把抽象目标包装成可测试的 prompt，或让遗传算法搜索框架。

  2. 02
    防御处理

    输入过滤、系统提示、spotlight、输出过滤；支持 5 种组合。

  3. 03
    模型推理

    Mock 离线占位，或调用任意 OpenAI-compatible 接口。

  4. 04
    成功评判

    规则 judge 快速筛，LLM judge 复核；支持集成评判。

  5. 05
    统计与报告

    ASR、Wilson CI、防御下降、FPR，自动生成 Markdown 报告。

这个工具做什么
v0.1.1

            
JailForge 把一次越狱评测拆成 攻击生成 → 防御处理 → 模型推理 → 成功评判 → 统计汇总 五个阶段，用统一的 ASR、防御下降幅度和良性误拦率比较不同组合。

            
    
              
  • 13 种静态攻击 + 遗传进化攻击
    • 
              
  • 5 种可消融防御配置
    • 
              
  • 规则 / LLM / 集成评判
    • 
              
  • ASR、Wilson CI、防御下降、FPR
    • 
              
  • CLI、桌面 UI、自动 Markdown 报告
    • 
            

          

          

            
伦理边界

            
    
              
  • 数据集只含抽象目标，不含配方 / payload / 真实账号
    • 
              
  • Mock 只输出占位符，不生成真实有害内容
    • 
              
  • 只测试自己有权调用的模型
    • 
              
  • 不发布完整有害输出；发现漏洞先私下披露
    • 
              
  • 报告同时呈现攻击成功率与防御的可用性代价
    • 
            

          

        

        

          

            
已知局限
务必阅读

            
    
              
  • 规则评判器会把“解码尝试 / 英文思维链”误判为成功，真实 ASR 需 LLM 复核或人工抽检。
    • 
              
  • 真实 pilot 只覆盖 8 条抽象目标，出现天花板效应，不能外推为模型整体安全性。
    • 
              
  • 良性集只有 16 条，FPR 估计很粗；下一版会扩到 100+ 条。
    • 
              
  • 单轮、文本、中文为主；多轮越狱与多模态尚未覆盖。
