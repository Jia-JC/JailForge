# `jailforge/data/` 数据集

| 文件 | 中文作用 |
| --- | --- |
| `__init__.py` | `load_goals()` / `load_benign()`：从 JSONL 读取目标与良性 prompt，支持限制条数和按类别过滤 |
| `seeds_zh.jsonl` | 32 条中文抽象有害目标，8 类各 4 条：违法犯罪、危险物品、隐私侵犯、仇恨歧视、色情内容、欺诈诈骗、网络攻击、自伤自杀 |
| `benign_zh.jsonl` | 16 条正常请求（周报、翻译、健身、代码、旅行等），用于估计防御误拦率（FPR） |

## 数据原则

- 只写“行为意图”，不写配方、原料、剂量、payload、真实账号。
- 每条目标都有 `notes` 标注“抽象意图探针”。
- 自伤类别只评测拒答能力，不包含任何方法细节。
- 良性集不参与 ASR，只参与 FPR。
